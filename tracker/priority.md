# Priority

The order of ongoing threads that shouldn't get dropped. Ongoing threads only - one-and-done
tasks stay as rows in [[schedule]].

**This file owns the ordering and nothing else.** Each line is a `#slug` plus a short label for
skimming. Deadlines, next steps and background live on the record in [[threads]]; dates live in
[[schedule]]. Don't restate them here.

Example (inside a fence, so it's never read as real data):

```
## High
- #gutters - gutter cleaning before the rains

## Medium
- #garage - garage cleanout

## Not ranked
- #smoke-alarms - twice-yearly alarm check
```
