# Changelog

Changes to the published Homefront skill (`.claude/skills/todays-todos/` and the `tracker/`
templates).

**Maintainer note:** update this file with every change to the skill pushed to GitHub, and bump
`.claude/skills/todays-todos/VERSION` to match the new heading. The planned update flow (see the
TODO in the README) reads this file to tell users, in plain language, what changed - so write each
entry for them, not for yourself. Call out anything that changes the tracker format (a renamed
field, a new section), since an update will need to migrate their files.

Version numbers: the last digit for fixes and rewording, the middle for new behavior, the first
for a change to the tracker format.
